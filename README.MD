# 🛵 حاسبة الطلبات | Delivery Orders Calculator

**تطبيق أندرويد مخصص لمساعدة مناديب التوصيل على تسجيل طلباتهم اليومية وحساب دخلهم ومستحقاتهم بدقة عالية.**<br>
يدعم التطبيق حساب الدخل التراكمي بناءً على شرائح الأسعار المخصصة، وحساب البونص وبدل البنزين تلقائياً (بثلاثة مستويات)، مع عرض كشوفات وتقارير مفصلة شهرياً وسنوياً، وإمكانية تصدير التقارير وحفظها في الجهاز أو مشاركتها مباشرة كملف `PDF`، بالإضافة إلى ميزة النسخ الاحتياطي واستعادة البيانات محلياً بدون إنترنت.

<p align="center" dir="ltr">
  <i>An Android app designed for delivery drivers to track daily orders and calculate earnings automatically. Features customizable pricing tiers, 3-level bonus & fuel allowance calculations, monthly and annual financial summaries, local JSON backup/restore, and full PDF report export, saving, and sharing.</i>
</p>

## ✨ أبرز المميزات | Key Features

💰 **حساب الدخل التراكمي**<br>
حساب تلقائي ودقيق للأرباح بناءً على شرائح الأسعار المخصصة.

⛽ **البونص وبدل البنزين (3 مستويات)**<br>
احتساب تلقائي للحوافز وبدل الوقود وفق ثلاثة مستويات قابلة للتخصيص.

📊 **تقارير وكشوفات مفصلة**<br>
عرض ملخصات مالية وإحصائيات دقيقة على مدار الشهر والسنة.

📄 **تصدير ومشاركة تقارير PDF**<br>
حفظ الكشوفات مباشرة في ذاكرة الجهاز أو مشاركتها كملف `PDF` جاهز للطباعة.

💾 **نسخ احتياطي محلي (Offline)**<br>
حفظ واستعادة البيانات محلياً بصيغة `JSON` بأمان تام ودون الحاجة للاتصال بالإنترنت.
